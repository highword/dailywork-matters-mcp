## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, tight list items |
| sm | 8px | Compact element spacing, button padding-y |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, sidebar item height |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Sidebar width gutter, page-level vertical rhythm |
| 3xl | 64px | Page top padding, hero spacing |

Exceptions:
- Sidebar width: 240px (fixed, collapses to 48px icon-only on narrow screens)
- Master-Detail split: left panel 280px minimum, right panel fluid
- Chart card minimum height: 256px
- Touch targets on interactive chart elements: 32px minimum (desktop tool, no 44px mobile target needed)

## Typography

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body | 14px | 400 (regular) | 1.5 | Inter |
| Label | 12px | 500 (medium) | 1.4 | Inter |
| Heading | 20px | 600 (semibold) | 1.2 | Inter |
| Display | 28px | 700 (bold) | 1.1 | Inter |
| Data | 14px | 400 (regular) | 1.4 | JetBrains Mono |
| Data-emphasis | 14px | 600 (semibold) | 1.4 | JetBrains Mono |

**Unique pixel sizes:** 12px, 14px, 20px, 28px (4 sizes).

**Data vs Body differentiation:** Data and Body share 14px but are visually distinct through typeface alone — JetBrains Mono's wider letterforms, tabular figures, and monospaced rhythm create immediate contrast against Inter at the same pixel size. No size gap is needed when the font family already provides sufficient differentiation.

**Weight justification (4 weights: 400, 500, 600, 700):** The Hermes developer-tool aesthetic (D-09) demands "strong weight variation" as an explicit design trait — precision tools use weight to encode information hierarchy (regular for prose, medium for labels/metadata, semibold for headings/emphasis, bold for display/hero). Restricting to 2 weights would flatten the typographic hierarchy and undermine the designed personality. This intentional deviation from the standard 2-weight limit is locked by D-09.

**Rules:**
- All task names, file paths, dates, and numeric values render in JetBrains Mono (Data role)
- Category labels and metadata keys render in Label role
- Page titles use Heading role; the app title in sidebar uses Display only once
- Body weight variation allowed: 400 for paragraphs, 500 for emphasis within prose
- Letter-spacing: -0.01em on Heading and Display; 0.02em on Label (uppercase labels only)

### Hermes Visual Layer (D-09)

| Effect | Specification |
|--------|---------------|
| Backdrop blur | `backdrop-blur-md` (12px) on sidebar, overlay panels, floating cards |
| Surface gradient (dark) | `bg-gradient-to-b from-white/[0.04] to-white/[0.01]` on cards |
| Surface gradient (light) | `bg-gradient-to-b from-white/80 to-white/60` on cards over blurred bg |
| Box shadow (cards) | `0 1px 2px rgba(0,0,0,0.05), 0 4px 16px rgba(0,0,0,0.04)` (light) |
| Box shadow (cards, dark) | `0 1px 2px rgba(0,0,0,0.3), 0 4px 16px rgba(0,0,0,0.2), inset 0 1px 0 rgba(255,255,255,0.03)` |
| Border style | 1px solid with `border-white/[0.06]` (dark) or `border-black/[0.08]` (light) |
| Border radius | 0px globally (sharp edges). Exception: avatar/status indicators at 50% |
| Transitions | 150ms ease-out for hover states; 200ms ease-out for page transitions |
| Active indicator | Left border 2px accent color on active sidebar item |

**Accent reserved for:**
1. Active sidebar navigation indicator (left border)
2. Primary action buttons (Generate Summary, Save Settings)
3. Chart interactive highlights (hovered segment, selected bar)
4. Links within summary prose
5. Progress indicator during generation SSE stream
6. Date picker selected date

**Never use accent for:** borders, backgrounds of inactive elements, icons in normal state, category badges.

## Interaction Patterns

### Navigation
- Sidebar items show hover state (muted background) and active state (accent left border + slightly brighter text)
- Page transitions: fade 200ms (no slide, keeps developer-tool precision feel)
- URL reflects current page and selected date: `/summaries/2026-05-20`, `/generate`, `/charts`, `/settings`

### Summaries Master-Detail
- Click date in left list: right panel loads detail with skeleton then content
- Active date highlighted in list
- Narrow screen (<768px): list view only, clicking date navigates to full-screen detail with back button
- Keyboard: arrow up/down navigates dates in list

### Generate
- Click "Generate Summary": button enters loading state (spinner icon replaces text), SSE stream displays progress events below
- On complete: toast success notification, auto-navigate to Summaries page showing the new date
- On error: inline error message below progress area (not toast — user needs to see context)

### Charts
- Drag chart cards via header grip area (6-dot grip icon)
- Resize via bottom-right handle
- Hover chart element: tooltip with exact value
- Click chart element: navigate to `/summaries/{date}` for that data point
- Time range change: all charts refetch with new range simultaneously
- Layout saved to localStorage key `dwm-chart-layout`

### Settings
- Form changes tracked; "Save Settings" button enables only when dirty
- Dirty state: subtle indicator (dot on Settings nav item)
- Reset: confirmation dialog, then reload config from disk defaults

## Responsive Breakpoints

| Breakpoint | Width | Behavior |
|------------|-------|----------|
| Desktop (default) | >= 1024px | Full layout: sidebar 240px + content |
| Tablet | 768-1023px | Sidebar collapses to 48px icon-only; Master-Detail left panel narrows to 200px |
| Mobile | < 768px | Sidebar hidden (hamburger toggle); Master-Detail becomes single-panel navigation |

**Desktop-first priority** (D-07): Mobile is functional degradation, not a design target. No touch-specific patterns needed.

## Animation & Transition Spec

| Element | Trigger | Duration | Easing | Property |
|---------|---------|----------|--------|----------|
| Button hover | mouseenter | 150ms | ease-out | background-color, box-shadow |
| Sidebar item hover | mouseenter | 100ms | ease-out | background-color |
| Page content | route change | 200ms | ease-out | opacity |
| Card hover | mouseenter | 150ms | ease-out | box-shadow, border-color |
| Chart tooltip | data hover | 100ms | ease-out | opacity |
| Skeleton shimmer | continuous | 1500ms | linear | background-position |
| SSE progress line | new event | 150ms | ease-out | opacity, transform(translateY) |
| Toast | show/hide | 200ms | ease-out | opacity, transform(translateY) |
| Dialog backdrop | open/close | 150ms | ease-out | opacity |
| Sidebar collapse | breakpoint | 200ms | ease-out | width |

**No animation on:** chart data transitions (Recharts handles internally with its own `animationDuration={300}`), scroll, form input.
