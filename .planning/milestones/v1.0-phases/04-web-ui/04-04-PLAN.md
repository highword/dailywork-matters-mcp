**1. category-donut.tsx** (D-11 item 1 — Donut chart):
- Props: `from: string`, `to: string`
- Uses `useStats('categories', from, to)`
- Recharts: `<PieChart><Pie data={data} dataKey="total_proportion" nameKey="category" innerRadius="60%" outerRadius="80%">` with `<Cell>` for each category colored per CATEGORY_COLORS
- Center label: total task count
- Tooltip: category name + percentage
- Click: no date-level navigation for aggregate chart

**2. time-bar.tsx** (D-11 item 2 — Horizontal Bar for time proportion):
- Props: `from: string`, `to: string`
- Uses same categories data but shows as horizontal bar chart
- Recharts: `<BarChart layout="vertical"><Bar dataKey="total_proportion" />`
- Each bar colored by CATEGORY_COLORS
- Tooltip: category + proportion %

**3. daily-trend.tsx** (D-11 item 3 — Line chart, task count over time):
- Props: `from: string`, `to: string`
- Uses `useStats('trends', from, to)`
- Recharts: `<LineChart><Line type="monotone" dataKey="task_count" stroke="var(--accent)" />`
- XAxis: dates (formatted as 'MMM d'), YAxis: task count
- Click on data point: navigate to `/summaries/${point.date}`

**4. category-trend.tsx** (D-11 item 4 — Stacked Area chart):
- Props: `from: string`, `to: string`
- Needs per-date per-category data. Use trends endpoint or derive from heatmap + categories.
- If the stats API doesn't provide per-date-per-category breakdown: aggregate from the general trends data by fetching all categories data and distributing. Alternative: create an `<AreaChart>` with stacked areas for each known category.
- Recharts: `<AreaChart><Area type="monotone" dataKey="feature" stackId="1" fill={CATEGORY_COLORS.feature} />`... one Area per category
- This chart may need a dedicated endpoint or client-side aggregation. For now, use the categories data to show proportion per category as a simplified stacked bar over time. Use placeholder data structure if the API endpoint doesn't perfectly match.

**5. heatmap-calendar.tsx** (D-11 item 5 — GitHub-style contribution heatmap):
- Props: `from: string`, `to: string`
- Uses `useStats('heatmap', from, to)` -> `[{ date, task_count }]`
- Custom implementation (Recharts doesn't have heatmap): Render a grid of small squares (14px each), grouped by week (7 rows for days of week, columns for weeks). Color intensity based on task_count: 0 tasks = muted bg, 1-2 = low accent opacity, 3-4 = medium, 5+ = full accent.
- Month labels above week columns
- Day labels (Mon, Wed, Fri) on left
- Tooltip on hover: "N tasks on May 20, 2026"
- Click square: navigate to `/summaries/${date}`

**6. file-activity.tsx** (D-11 item 6 — Horizontal Bar, top N files):
- Props: `from: string`, `to: string`
- Uses `useStats('files', from, to)` -> `[{ file, count }]` (top 20)
- Recharts: `<BarChart layout="vertical"><Bar dataKey="count" fill="var(--accent)" />`
- YAxis: file paths (truncated to last 2 segments if too long)
- Show top 10 entries
- Tooltip: full file path + count

**7. hours-radial.tsx** (D-11 item 7 — Work hours distribution):
- Props: `from: string`, `to: string`
- Uses `useStats('hours', from, to)` -> `[{ date, created_at }]`
- Parse `created_at` times, group by hour (0-23), count entries per hour
- Recharts: `<RadialBarChart>` with 24 bars representing hours. Or use `<PieChart>` with 24 segments representing hours of the day (a clock visualization).
- Alternative simpler approach: Use a BarChart with 24 bars (one per hour, x-axis 0-23), height = activity count. This is clearer than a radial chart.
- Color: accent for working hours, muted for off-hours
- Tooltip: "Hour {h}:00 - {count} summaries"

**8. project-allocation.tsx** (D-11 item 8 — Treemap or Stacked Bar):
- Props: `from: string`, `to: string`
- Uses `useStats('projects', from, to)` -> `[{ project, task_count, total_proportion }]`
- Recharts: `<Treemap data={data} dataKey="total_proportion" nameKey="project" />` with custom content rendering showing project name
- Each project gets a unique color (cycle through a palette)
- Tooltip: project name + task count + proportion %
- Click: navigate to summaries page (filtered, or just general navigation)
